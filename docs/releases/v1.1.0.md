# Codebase to Mastery v1.1.0

Standard npm package distribution and clearer inspiration credits / 标准 npm 包与更清晰的来源说明。

## Changes / 变更

- Added a standard `package.json`, executable `codebase-to-mastery` installer and actual `npm pack` `.tgz`. The Node installer has no dependencies or install lifecycle hooks. It preflights every target and preserves existing Skill folders.
- Added explicit English/Chinese README credits for Zara Zhang's [codebase-to-course](https://github.com/zarazhangrui/codebase-to-course), a design comparison, and four additional learning-method inspirations with pinned source records.
- Extended release packaging to verify that the npm tarball contains exactly the same committed resources as the ZIP/tar.gz. All assets are covered by the manifest and SHA-256 checksums.
- Added npm installer behavior tests and a CI smoke install from the packed tarball.

The progressive learning workflow and refreshed offline UI from v1.0.0 are retained. The previous release stays available.

## Install / 安装

From your project directory:

```bash
npx --yes --allow-remote=all \
  --package=https://github.com/StormTian/codebase-to-mastery/releases/download/v1.1.0/codebase-to-mastery-1.1.0.tgz \
  codebase-to-mastery --agent codex claude-code
```

Requires Node.js 18+. Use `--global` for personal installation, `--dry-run` to preview targets, or `--directory /path/to/skills` for another Agent Skills client. The installer copies the Skill; the learning helpers require Python 3.10+ and Git. An existing target is reported and preserved; move it aside before reinstalling.

Compatibility correction, 2026-10-02: npm 12 requires `--allow-remote=all` for this URL installation. The command above includes the per-command option; v1.1.0's published archives retain their original README. Use [v1.1.1](v1.1.1.md) for archives with the corrected instructions. Existing v1.1.0 assets and tag remain unchanged.

Alternatively, use the standard Skills CLI:

```bash
npx skills add https://github.com/StormTian/codebase-to-mastery/tree/v1.1.0 \
  --skill codebase-to-mastery --agent codex claude-code
```

The npm tarball is hosted by **GitHub Releases**. It is not registered on npmjs.com or GitHub Packages; the direct `npx` command therefore uses the full download URL.

## Download assets / 下载文件

- `codebase-to-mastery-v1.1.0.zip` and `.tar.gz`: manual Skill install archives, root `codebase-to-mastery/`.
- `codebase-to-mastery-1.1.0.tgz`: standard npm pack archive, root `package/`, executable through npx.
- `release-manifest.json`: exact source commit and per-file/archive checksums.
- `SHA256SUMS`: verifies the three archives and the manifest.

Download all five assets to one directory:

```bash
shasum -a 256 -c SHA256SUMS
# Linux alternative: sha256sum --check SHA256SUMS
```

Credits and design comparisons concern the [reviewed source revisions](https://github.com/StormTian/codebase-to-mastery/blob/v1.1.0/references/provenance.md). The implementation and assets were written independently. Passing package and fixture tests establishes distribution behavior; learner mastery still requires assessed learner work.
