# Codebase to Mastery v1.1.1

Correct direct URL installation for npm 12 / 修正 npm 12 的远程安装说明。

The latest npm tarball is now available at the repository root as `codebase-to-mastery.tgz`. Both READMEs use its stable URL and the latest-release page without asking readers to select a version. The command supplies the per-command `--allow-remote=all` option required by npm 12 for GitHub tarball URLs, with a downloaded-file fallback. Packaging excludes the root archive to avoid recursive inclusion; CI compares it with the newly packed tarball before publication. The zero-dependency installer, progressive learning workflow, original UI, inspiration credits and design comparison from v1.1.0 are retained. Existing releases and their assets remain available.

## Install / 安装

From your project directory / 在目标项目目录执行：

```bash
npx --yes --allow-remote=all \
  --package=https://raw.githubusercontent.com/StormTian/codebase-to-mastery/main/codebase-to-mastery.tgz \
  codebase-to-mastery --agent codex claude-code
```

This setting applies only to the command and does not modify global npm configuration. [npm 12 defaults to refusing remote tarball URLs](https://docs.npmjs.com/cli/v12/using-npm/config/#allow-remote). You can also download the `.tgz` and run:

```bash
npx --yes --package=/absolute/path/codebase-to-mastery.tgz \
  codebase-to-mastery --agent codex claude-code
```

Requires Node.js 18+; learning helpers require Python 3.10+ and Git. Default targets are the current project's `.agents/skills/codebase-to-mastery` and `.claude/skills/codebase-to-mastery`. Existing Skill folders are preserved. Use `--dry-run`, `--global`, or `--directory /path/to/skills` when needed.

通用 Skills CLI 也可安装固定版本：

```bash
npx skills add https://github.com/StormTian/codebase-to-mastery/tree/v1.1.1 \
  --skill codebase-to-mastery --agent codex claude-code
```

## Package and verification / 包与校验

The five assets are ZIP, tar.gz, the standard npm `.tgz`, `release-manifest.json` and `SHA256SUMS`. The three archives contain the same committed resources. Download all five into one directory and run:

```bash
shasum -a 256 -c SHA256SUMS
```

The npm package is hosted in **GitHub Releases**; it is not published to npmjs.com or the GitHub Packages registry. Python/Node tests, packed-resource checks and teaching fixtures establish distribution behavior; they do not measure learner mastery. See [validation](../validation.md) and [inspiration sources](../../references/provenance.md).
